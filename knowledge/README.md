# Emma's Shared Knowledge

This is the shared brain for every Emma on the team. Your Emma reads this before working, and you contribute back what you learn so the next person's Emma is smarter than yours was.

**Emma works across repos** — she doesn't live in any one site. This knowledge base travels with her: clone or reference it alongside whatever project you're working in, and Emma applies what's here.

## How it's organized

| Folder | What lives here |
| --- | --- |
| [`conventions/`](./conventions/) | Coding standards, CSS/JS patterns, naming rules, David's Model discipline. The "how we write code" layer. |
| [`blocks/`](./blocks/) | Reusable block patterns, gotchas, and known-good structures. One file per block type or pattern. |
| [`recipes/`](./recipes/) | Step-by-step how-tos for repeatable tasks (migrations, common fixes, setup). |

## How Emma uses this

1. On any EDS task, Emma checks the relevant folder here first — conventions before writing code, blocks before building one, recipes before reinventing a workflow.
2. If the knowledge is missing or wrong, Emma says so and (with your OK) proposes an addition.
3. New knowledge is contributed via a PR — see [CONTRIBUTING-TO-EMMA.md](../CONTRIBUTING-TO-EMMA.md).

## The rule

Every entry is one focused fact or pattern, written so *someone else's Emma* can apply it cold — no missing context, no "you had to be there." If you can't explain it that cleanly, it's not ready to share yet.
