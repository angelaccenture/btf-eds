# Recipes

Step-by-step how-tos for repeatable tasks — migrations, common fixes, project setup, anything you'd otherwise re-figure-out every time.

## What a good recipe has

- **When to use it** — the trigger, in one line.
- **The steps** — numbered, in order, copy-pasteable where possible.
- **How to verify** — how you know it worked.

If you did something more than once, it's a recipe. Write it down here so nobody's Emma has to reverse-engineer it again.
