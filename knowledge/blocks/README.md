# Block Patterns

Reusable block patterns, known-good structures, and the gotchas that cost someone an afternoon. One file per block type or pattern.

## What a good entry has

- **The content contract** — the initial authored structure the block expects (what the author types before decoration).
- **The decoration approach** — how the JS transforms it, and why.
- **Gotchas** — the thing that broke, and how to avoid it.

Before building any block, check here first — chances are someone's Emma already solved it. If not, build it, then add the pattern so the next person doesn't start from zero.
