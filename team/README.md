# The Team

One profile per teammate, so we all know who each other is — who owns what, who to ask, timezones for handoffs, and a bit of the human behind the work.

## How this gets filled in

Each teammate's Emma creates and maintains their profile:

1. On setup (or first session), your Emma checks for `team/<your-name>.md`.
2. If it's missing, she asks you a few friendly questions (from [`TEMPLATE.md`](./TEMPLATE.md)) and writes the file from your answers.
3. She keeps it current as your focus changes, and commits it back so the team sees it.

## The rules

- **One file per person**, kebab-case named after the teammate (e.g. `chris-desouza.md`).
- **Only what you're happy to share** — this is a shared repo. Nothing personal you haven't okayed.
- **Keep it human and light.** This is for the team to know each other, not an HR form.

Start from [`TEMPLATE.md`](./TEMPLATE.md).
